# my NEAT Library
This repository is my implementation of the NEAT algorithm, a Neuroevolution AI training algorithm. It will have my implementation in C++ and a few examples of its application. The implementation is (hopefully) finished, and is currently being tested.

Neuroevolution is a topic that interests me. I have made simple neuroevolution projects in the past. I recently revisited [the last one](https://github.com/bojandam/ProektnaMatura) I made, which was an attempt to make the AI train on each other in a tournament like system. Revisiting it inspired me to "take the next step", which I tought was implementing a more applicable algorithm, like NEAT.

The implementation strictly followed [The original NEAT paper](https://nn.cs.utexas.edu/downloads/papers/stanley.ec02.pdf).

Development has slowed down due to my focus on my studies.
